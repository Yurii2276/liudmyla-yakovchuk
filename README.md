# Liudmyla Yakovchuk — Official Author Website

Static bilingual author website for **Liudmyla Yakovchuk** and the novel  
**Remember Who You Are: A Ukrainian Family Saga of Love, War, and Memory**.

## Included

- English / Ukrainian language switch
- Book overview and Amazon link
- Book trailer
- Song inspired by the novel
- Audiobook placeholder (“Coming Soon”)
- Author biography and Author’s Note
- Ukrainian print-edition gallery
- Separate **Media & Events** page
- Instagram, YouTube and Amazon links
- Mobile responsive layout

## Publish with GitHub Pages

1. Create a new **public** GitHub repository.
2. Upload **all files and folders from this ZIP to the root of the repository**.
   - `index.html` must be in the repository root.
   - Keep the `assets` folder unchanged.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Save.
6. After GitHub publishes it, your site will be available at an address similar to:
   `https://USERNAME.github.io/REPOSITORY-NAME/`

## Important

Do not upload the ZIP itself as the website. Extract it first and upload the contents.
